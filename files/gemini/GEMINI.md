# Project Mandates

- **80-Column Limit:** All generated text output, including markdown content and descriptions, must adhere to an 80-column line limit. This applies to all content, not just code.
- **Expert Routing:**
  - When working on Ansible roles or tasks (e.g., `roles/`, `tasks/`, `site.yaml`), prioritize the `ansible-expert` skill.
  - When working on files in `roles/python/`, prioritize the `python-programmer` skill.
  - When working on files in `roles/haskell/`, prioritize the `haskell-programming-reviewer` skill.
  - For markdown documentation, use `markdown-validator`.
- **Documentation Review:** For exhaustive document reviews, the user should prefer activating the `document-critique` or `markdown-validator` skills.
